# 国内12社の企業ロゴ掲載・事前調査

- 確認日：2026-11-20（日本時間）
- Timeline参照：`tree-164c2d05cc066528` / task `jp`。共有Timelineの編集なし。
- 想定用途：第三者運営の「デザインシステムカタログ」のトップ／一覧で、提供元識別のため企業ロゴを継続表示する。報道記事、公式パートナーサイト、各社からの受託制作とは限らない。
- 調査のみ。ロゴの導入、UI変更、権利者への申請・連絡はしていない。

## 判定の読み方

本書は公開された公式資料の確認記録と、実装前の保守的な運用判断であり、法律上の最終判断ではない。「許諾未確認」は禁止が確定したという意味ではなく、**公開されている／ダウンロードできるというだけでは掲載許可と扱わない**という意味。

- **申請・個別許諾**：公式文言に申請・確認・明示許諾の要求あり。承認前は掲載保留。
- **対象限定／条件付き**：広報、報道・メディア、パートナー、ユーザー等に公開利用条件あり。独立カタログが該当するか自動判断せず、範囲外・曖昧なら問い合わせる。
- **不明／未確認**：外部カタログのロゴ使用を認める条項を確認できない。取得失敗、本文抽出不能も含み、掲載保留。

企業ロゴ、サービスロゴ、DS（デザインシステム）ロゴは別の標章である。企業ロゴの許諾をDSロゴに、またはその逆に流用しない。MIT・Apache等のOSSコードライセンスや、FigmaファイルのCCライセンスを、そのまま企業／DSの商標使用許諾とは扱わない。一般的なリンク許可もロゴ画像の転載許可とは異なる。faviconや公式サイトからの画像抽出も許諾の代替にしない。

## 実装へ進む前に必要な確認

1. 会社・サービス・DSのどのロゴを使うか固定する。企業識別ならサービスロゴで代替できると決めつけない。
2. 各社へ必要に応じて、公開URL、一覧／トップの見本、目的、表示寸法、継続掲載、非公式・非提携、画像を公開リポジトリに含めるかを示す。掲載許可と素材再配布許可を分けて確認する。
3. 利用資格・対象媒体・事前審査・最小寸法・保護領域・色・改変不可・取消時の対応を記録する。今回確認できなかったZIP／画像のみPDF／動的サイト／403の条項を追加確認する。
4. 許諾を確認できるまではロゴ表示に進まず、提供元名の通常テキストと公式リンクを基本の代替案とする（商標名の表示自体について必要な法的評価は別途行う）。

**この調査だけで12社のロゴを一括導入してよいという結論ではない。** 明示的に対象の広い条件付き提供が見えるpixiv・SmartHRも、本カタログ用途の適合や表示規定の確認が残る。
