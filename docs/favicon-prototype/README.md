企業ロゴの許諾調査は[調査サマリー](<../research/company-logo-usage.md>)とリンク先の4資料に保存・保持している。今回のfavicon案で置き換えない。

## 表示案

- ホームのグリッドと、詳細画面の左側一覧・モバイル一覧で同じ処理を使う。
- サムネイル内の左上8pxに、36pxの白い角丸バッジ。favicon本体24px。モバイルは左上6px、バッジ30px、本体20px。
- カードのレイアウト・並び順・元のサムネイル画像は変更しない。
- アイコンは装飾扱い。読み上げやタブ移動の項目を増やさず、カードのクリック・キーボード操作を妨げない。
- 欠損・画像読込エラー時はバッジごと非表示。企業ロゴ素材や自作アイコンでは補わない。
- オーバーレイのため、サムネイル内の左上の見出し等と重なる。この重なりを含む見た目をレビューするための試作。元サムネイルの構図・内容は改変していない。

## 素材と注意

全67件中59件取得、8件欠損。[全件の出典と取得記録](<../research/site-favicon-sources.md>)を保存。第三者favicon APIは使用していない。

公式サイトで宣言されるfaviconには、企業マーク、Storybook、GitHub、Figma等が含まれる。すべてをDS独自のロゴとは呼ばない。faviconの取得は再利用許諾の確認ではなく、企業ロゴの許諾回避策でもない。公開条件は別途確認する。
